## 1. 上一版实测问题（我逐帧看了截图）

| # | 问题 | 现象 | 根因 |
| --- | --- | --- | --- |
| P1 | **脚底打滑（skating）** | 窗口匀速横移，但 webm 跑步循环按自己节奏播，脚像在"滑冰" | 窗口位移速度≠动画里脚的步频，二者没有同步 |
| P2 | **朝向不一致** | 往右跑时鱼还朝左边 / 姿态与方向对不上 | 没有「跑步方向 → 翻转/选对应曲线」的映射 |
| P3 | **台词被裁** | "下班啦——！"气泡顶边被切掉 | 窗口高度不够、气泡超出 240×260 区域且无留白 |
| P4 | **构图空旷** | 鱼偏小、四周大片空白 | 覆盖窗比例与 object-fit 没调好，气泡/鱼没占满 |
| P5 | **机器人感** | 线性匀速、突然起停 | 无缓入缓出（ease-in-out）、无预备发力/收尾 |
| P6 | **节奏单调** | 2 趟来回一气呵成，缺起伏 | 只有"跑"，没有 起步欢呼→跑→跳→庆祝→谢幕 的层次 |
| P7 | **压任务栏** | 跑线过低，贴着任务栏 | 跑线 Y 用比例估算，未避开任务栏工作区底边 |

> 结论：不是"有 bug 跑不起来"，而是**观感不专业**。核心是 P1/P2 —— 正如 Mocha Casa 说的：
> > "如果窗口移动太快、太慢或相位不对，动物看起来就像在滑冰。"
> 所以 v2 的重点是**让"位移"与"步频"对齐，并给方向和缓动**。

## 2. 优秀案例的关键手法（提炼成可落地项）

1. **脚底不滑 = 位移与步频同步**（Mocha Casa）：屏幕位置 = 窗口位置 + 动画帧内脚的位置。
   实践做法：**按动画片段里"一步的时间/一步的距离"推算窗口每帧该走的像素**，让 `窗口速度 = 步长/步时`；
   或者反过来**由窗口速度决定动画播放速率**（对 webm 用 `playbackRate` 微调）。二者取其一对齐即可。
2. **有限动作状态机**（Mocha Casa）：区分"循环状态（跑/待机）"与"一次性动作（跳/庆祝）"，
   一次性动作播完才回到循环，不能半路被打断。→ 我们已有节拍系统，改造为显式状态机。
3. **朝向左/右**（Shimeji / 通用）：向左跑镜像翻转，向右跑正常朝向；换向时先"刹住"再转身，别瞬移。
4. **贴地跑线，避让任务栏**（modbender）：脚踩在"地面线"上，地面线取 `workArea` 底边（已排除任务栏）。
5. **避让鼠标**（modbender，可选）：鼠标 250px 半径内不把鱼盖上去（可用 z 序/绕行，简化版：踩到就跑开）。
6. **气泡自适应时长 + 不裁切**：气泡放窗口内、留足上边距，按字数自动停留时间。
7. **两种节奏模式**（Mocha Casa）：给用户一个"安静/活跃"档位，避免过度打扰。

## 3. 改进方案（技术做法）

### 3.1 修 P1 脚底打滑 —— 位移 × 步频对齐（核心）
- 先测出每个跑步 webm 的**单步时长**（侧身跑 / 开心小跑各测一次，写进 manifest 常量 `stepMs`）。
- 渲染层把"当前片段 + 当前播放进度"回报主进程（或用固定曲线驱动）。
- 主进程用一个**统一时钟**推进：`窗口x += 每步像素 × (Δt / stepMs)`，同时让动画 `playbackRate`
  = `窗口目标速度 / 该片段的自然速度`，**反向锁相**，使脚落地处相对屏幕静止。
- 提供后备：若某片段步频差异太大，则该段改播"原地跑/蹬腿"动画 + 窗口仍前进（视觉上仍成立）。

### 3.2 修 P2 朝向 —— 方向映射
- 向左跑启用 `scaleX(-1)`（用 CSS `transform` 镜像，透明视频镜像不掉质量）；
- 换向前在端点播一个短"急停转身"（用 `a053` 旋转 或 快速镜像切换），避免硬切。

### 3.3 修 P3/P4 构图与气泡
- 覆盖窗改为 **300×320**（更高更宽），鱼 `object-fit: contain` 充满下半，气泡在上方独立区带留白；
- 气泡 `max-width`、多行自动换行、**按字数计算停留时长**，永不裁切；
- 让鱼脚底对齐窗口底部（跑线贴近地面），四周留一点柔光而非大片空白。

### 3.4 修 P5 缓动 —— 曲线运动
- 参照**五次/三次 ease-in-out** 的速度曲线（用 `easeInOutCubic`），起步加速、到端点减速；
- 起步前加 **120ms 预备**（下蹲蓄力 `a025`）、收尾加 **settle**（站定喘息）。

### 3.5 修 P6 丰富层次 —— 一段完整的"下班小剧场"（约 9 秒）
```
[0.0～0.7s] 从主窗钻出（滑出）＋ 开口：「下班啦——！」
[0.7～4.5s] 向一侧开心小跑（方向×1）＋ 每 1.2s 换一句台词，脚不滑
[4.5～4.9s] 端点急停转身（旋转）
[4.9～7.5s] 反向跑回（镜像）＋ 台词
[7.5～8.5s] 原地跳跃 + 撒花烟花（a074）＋「今天也辛苦啦！」
[8.5～9.0s] 挥手告别（a083）→ 淡出销毁
```
- 台词池补足"下班啦"类短句，且**跑动方向一致**时同一句不重复。

### 3.6 修 P7 跑线 —— 贴地避任务栏
- 跑线 Y = `workArea.bottom - winHeight`（脚踩工作区底），再夹紧不出界。

### 3.7 稳健性（保留上一版优点）
- 点击穿透 / 置顶 / 不抢焦点 / 失败兜底 / 开关 / reduceMotion 全部保留。
- 新增：**鼠标避让**（简易：跑线在光标正下方且很近时，抬高 20px 绕开）作为可选彩蛋。
